# Network simulation files

- F2_Team19_Config.json contains full simulation and policy parameters.
- F2_Team19_Topology.json stores actual nodes, initial levels, links and link qualities.
- ../simulator.py executes the model.
- ../results/F2_Team19_Simulation.json contains the full default comparison.

From the root: `python scripts/run_simulation.py`.

No `.pkt` file applies to this custom Python implementation. These JSON inputs
and the complete source are the reproducible network simulation files.
